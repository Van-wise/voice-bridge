## 项目结构详解

### Backend (FastAPI)
```
backend/
├── main.py                    # HTTPS 主入口 (端口 7266)
│   ├── FastAPI 应用配置
│   ├── CORS 中间件
│   ├── WebSocket 路由注册
│   └── 生命周期管理
│
├── start.py                   # HTTP 启动器（仅文字同步）
│
├── generate_cert.py           # SSL 证书生成工具
│
├── requirements.txt           # Python 依赖声明
│   ├── fastapi, uvicorn
│   ├── sounddevice, numpy    # 虚拟麦克风
│   └── pyautogui             # 自动粘贴
│
├── certs/                     # SSL 证书目录
│
├── shared/                    # 共享模块
│   ├── config.py             # 配置管理
│   ├── database.py           # SQLite 数据库
│   └── errors.py             # 错误定义
│
├── devices/                   # 设备管理核心
│   ├── router.py             # 设备 API 路由
│   ├── websocket.py          # WebSocket 处理
│   ├── microphone.py         # 手机麦克风 WebSocket
│   ├── ffmpeg_router.py       # FFmpeg 音频解码 (Opus→PCM)
│   └── virtual_mic.py         # 虚拟麦克风 (sounddevice)
│
└── clipboard/                 # 剪贴板同步
```

### Frontend (Vue 3)
```
frontend/
├── src/
│   ├── main.ts               # Vue 入口
│   ├── App.vue               # 根组件
│   │
│   ├── components/           # UI 组件
│   │   ├── SimpleRecorder.vue  # 录音 + 文字同步 + 手机麦克风
│   │   └── MicrophoneBridge.vue  # 手机麦克风组件
│   │
│   └── composables/          # 组合式函数
│
├── public/
│   └── setup.html            # 证书安装引导页
│
├── dist/                     # 构建产物
└── package.json              # npm 依赖
```

## 核心功能文件

### 1. 手机麦克风功能
| 文件 | 用途 |
|------|------|
| backend/devices/microphone.py | WebSocket 音频接收 |
| backend/devices/ffmpeg_router.py | Opus → PCM 解码 |
| backend/devices/virtual_mic.py | 虚拟麦克风输出 |
| frontend/src/components/MicrophoneBridge.vue | 前端麦克风组件 |

### 2. 文字同步功能
| 文件 | 用途 |
|------|------|
| backend/clipboard/ | 剪贴板同步服务 |
| backend/devices/websocket.py | WebSocket 通信 |

### 3. 录音功能
| 文件 | 用途 |
|------|------|
| frontend/src/components/SimpleRecorder.vue | 录音卡片 |
